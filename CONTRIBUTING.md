# Contributing to Task Management

Thanks for helping improve **Task Management**, a PHP + MySQL web app for projects, tasks, progress tracking, user roles and reports.

## Ways to contribute

- Report a bug or suggest an idea in [Issues](https://github.com/swapnilchaudhari007/TASK_MANAGEMENT/issues/new/choose)
- Pick up an issue labelled `good first issue` or `help wanted`
- Improve docs, examples or translations
- Review open pull requests

## Local setup

```bash
git clone https://github.com/<your-username>/TASK_MANAGEMENT.git
cd TASK_MANAGEMENT
# Requires PHP 7.4+ and MySQL (e.g. XAMPP)
# 1. Copy the project into your web root (e.g. htdocs/)
# 2. Import the SQL file from database/ into MySQL
# 3. Set your DB credentials in db_connect.php
# 4. Open http://localhost/TASK_MANAGEMENT
```

## Workflow

1. Fork the repo and create a branch: `git checkout -b feat/short-description`
2. Keep each PR focused on one change
3. Use [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`
4. Open a PR against `main` and fill in the template

## Areas you can work on

- Projects
- Tasks
- Progress tracking
- Users & roles
- Reports
- Login / auth

## AI-assisted contributions

AI tools are welcome. You are responsible for every line you submit: review it, test it and say in the PR if AI helped.
